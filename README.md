# Robofin

**Live site:** https://jasminebrunstrom-glitch.github.io/robofin

Landing page for Robofin, an early-stage concept: brand-independent, pay-per-use financing for robots in Europe.

**Idea:** integrators sell robots, and their customers pay monthly or per use instead of upfront. Credit decisions would combine customer financials with robot usage data.

**What's here:** a single static page (`index.html`). Demo screens use fictional companies and numbers.

**Status:** concept stage.
